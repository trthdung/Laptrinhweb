**Website Cá Nhân – Giới Thiệu Bản Thân & Dự Án**

Đây là website cá nhân được xây dựng nhằm giới thiệu thông tin cá nhân, quá trình học tập và các dự án đã thực hiện. Website có giao diện đơn giản, hiện đại với tông màu hồng nhạt, phù hợp với phong cách cá nhân.
Website được thực hiện bằng PHP, HTML và CSS, chạy trên môi trường máy chủ hỗ trợ PHP.

**Công nghệ sử dụng**

- PHP: Khai báo và quản lý dữ liệu cá nhân, danh sách dự án và hiển thị dữ liệu động.
- HTML: Xây dựng cấu trúc và nội dung của trang web.
- CSS: Thiết kế giao diện, màu sắc, bố cục, hiệu ứng và khả năng hiển thị trên màn hình nhỏ.

**Cấu trúc thư mục**

Website được xây dựng trong một file PHP duy nhất:
personal-website/
│
├── about.php
│

**Mục tiêu**

- Thực hành xây dựng trang web bằng PHP.
- Hiểu cách sử dụng biến và mảng trong PHP.
- Biết cách sử dụng echo để đưa dữ liệu PHP ra HTML.
- Biết sử dụng vòng lặp foreach để hiển thị dữ liệu.
- Kết hợp PHP với HTML và CSS.
- Xây dựng một trang Portfolio cá nhân đơn giản.
